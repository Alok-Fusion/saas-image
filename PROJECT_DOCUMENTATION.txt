1. PROJECT OVERVIEW
================================================================================

ImageKit Pro is a free, browser-based SaaS application offering 20+ image
processing tools. All processing happens client-side — no images are ever
uploaded to a server.

App Name:       ImageKit Pro
Live URL:       https://imagekitpro.cc
Package Name:   image-utility-saas
Version:        1.0.0
License:        (see LICENSE file)

DATA FLOW
─────────
  1. User visits URL (e.g., /#/compressor)
  2. App reads hash → sets currentTool state
  3. Dynamic SEO updates document.title + meta description
  4. Tool component renders with onBack callback
  5. ToolSuggestionsBar renders below tool with related tools
  6. On tool selection: hash updates, addRecent() called, state changes
  7. On back: hash cleared, homepage renders with favorites/recents

STATE MANAGEMENT
───────────────
  • React useState for currentTool (synced with URL hash)
  • useFavorites() hook → localStorage key: "imagekit_favorites"
  • useRecentlyUsed() hook → localStorage key: "imagekit_recent"
  • No external state library needed (all local state)

ROUTING
───────
  • Hash-based routing (no react-router dependency)
  • Format: /#/{tool-slug}  (e.g., /#/compressor, /#/background-remover)
  • Supports browser back/forward via popstate listener
  • Direct URL access works (deep linking)

6. FEATURE: Tool-Specific URLs (Hash-Based Routing)
================================================================================

PURPOSE
  Each tool now has a unique, shareable URL using hash-based routing.

HOW IT WORKS
  • URL format: https://imagekitpro.cc/#/{tool-slug}
  • Examples:
    - /#/compressor       → Image Compressor
    - /#/background-remover → Background Remover
    - /#/ocr              → OCR Text Extractor
  • Home page: no hash (just the base URL)

IMPLEMENTATION
  • getToolFromHash() reads window.location.hash on mount
  • setHashForTool() updates hash via history.pushState
  • popstate event listener enables browser back/forward navigation
  • No external router dependency — zero added bundle size

FILES MODIFIED
  • src/App.tsx — Added hash routing logic

8. FEATURE: Smart Tool Suggestions
================================================================================

PURPOSE
  After using a tool, users see 3 related tools they might want next.

HOW IT WORKS
  • Each tool maps to 3 curated suggestions (hardcoded relationship map)
  • Displayed as a glassmorphism bar below the active tool

10. FEATURE: Favorites & Recently Used
================================================================================

PURPOSE
  Users can star favorite tools and see recently used tools for quick access.

FAVORITES (⭐)
  • Star button (★/☆) on each tool card
  • Persisted in localStorage (key: "imagekit_favorites")
  • "Your Favorites" section appears at top of homepage when items exist
  • Toggle: click star to add/remove

RECENTLY USED (🕐)
  • Automatically tracked when any tool is opened
  • Max 6 items, most-recent-first ordering
  • Persisted in localStorage (key: "imagekit_recent")
  • "Recently Used" section appears below favorites on homepage

FILES CREATED
  • src/hooks/useFavorites.ts       — Custom React hook
  • src/hooks/useRecentlyUsed.ts    — Custom React hook

FILES MODIFIED
  • src/App.tsx      — HomePage renders favorites/recents sections
  • src/index.css    — Favorite button styling (★ gold glow effect)

11. DESIGN SYSTEM
================================================================================

THEME
  • Primary: Dark background (#0a0a0f)
  • Gradients: Purple-blue (#667eea → #764ba2), Pink (#f093fb → #f5576c)
  • Glassmorphism: Semi-transparent cards with backdrop-filter blur
  • 3D Effects: CSS perspective, rotateX on card hover, floating shapes

CSS VARIABLES (src/index.css)
  • 40+ custom properties organized by category:
    - Colors (--color-bg-*, --color-text-*, --color-border-*)
    - Gradients (--gradient-primary, --gradient-secondary, etc.)
    - Spacing (--spacing-xs through --spacing-3xl)
    - Typography (--font-size-xs through --font-size-5xl)
    - Border Radius (--radius-sm through --radius-full)
    - Shadows (--shadow-sm, --shadow-md, --shadow-lg, --shadow-glow)
    - Transitions (--transition-fast, --transition-base, --transition-slow)
    - Z-index (--z-dropdown, --z-modal, --z-tooltip)

KEY ANIMATIONS
  • fadeInUp — Page entrance animation
  • floatShapes — Background ambient floating effect
  • pulse — Logo icon & NEW badge pulse
  • bounce — Dropzone icon bounce
  • spin — Processing spinner

RESPONSIVE BREAKPOINTS
  • Mobile: max-width 768px
    - Font sizes reduced
    - Tools grid → single column
    - Header stacks vertically
